# Shields

Browser library of LEGO minifig shield designs for 3D-printed magnetic pins.

Open `index.html` to search and filter the shields, view each design, copy its LDraw `.dat` code, and match its LEGO colours to Bambu Lab PLA filaments.

- Each design is the printed or sticker surface only: the shield body (and sticker paper) is removed, and all subfiles and primitives are inlined into one self-contained file.
- Bare-plastic areas use the colour LEGO made each shield in (from Rebrickable set inventories).
- Bambu colours come from Bambu Studio's `filaments_color_codes.json`.
